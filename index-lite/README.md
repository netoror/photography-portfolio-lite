|------|--------|---------|

| 点赞系统 | ✅ 完整 | ✅ 完整 |

- 🚀 **快速加载**：无 Hero 区域，打开即见作品

- 💾 **轻量简洁**：去除不必要的视觉装饰

## 📝 使用方法

### **直接打开：**
```html
<a href="摄影网站/index-lite/index.html">打开 Lite 版主页</a>
<a href="摄影网站/index-lite/about.html">打开独立 About 页面</a>
```

### **嵌入现有网站：**
```html
<!-- 引入样式 -->
<link rel="stylesheet" href="路径/css/style_lite.css">

<!-- 引入 JS -->
<script src="路径/js/main_lite.js"></script>
```

## 🔧 图片路径配置

Lite 版的图片路径指向版本 A 的原始图片：
- **缩略图**: `./images/*.jpg`（local images）
- **原图**: `../versions/a-version/images/*.jpg`（original images）

这样可以在保持 Lite 版简洁的同时，使用高质量的原始图片。
