========================================
  🟢 最推荐：使用在线转换工具
========================================

推荐网站（任选其一）：

1️⃣ **CloudConvert** (https://cloudconvert.com/heic-to-jpg)
   ✅ 支持批量上传
   ✅ 保持原质量
   ✅ 免费使用
   
2️⃣ **iLoveIMG** (https://www.iloveimg.com/heic-to-jpg)
   ✅ 简单易用
   ✅ 限制 50MB/天
   ✅ 免费

3️⃣ **CloudConvert** (https://cloudconvert.com/heic-to-jpg)
   ✅ 专业工具
   ✅ 支持 API

📝 操作步骤：
   1. 访问上述任一网站
   2. 点击「选择文件」上传你的 HEIC 文件夹
   3. 等待转换完成（通常 10-30 秒）
   4. 下载所有 JPG 文件
   5. 覆盖到原文件夹位置

✅ 优点：不需要安装任何软件，快速简单！

========================================
  🟡 备选方案：Windows Photo Viewer
========================================

操作步骤（需要手动操作）：

1. 在 Windows 资源管理器中打开 HEIC 文件文件夹
2. 右键点击任意 HEIC 文件 →「打开方式」→「照片」
3. 在照片应用中，选择「另存为」或截图保存
4. 重复操作直到所有文件转换完成

⚠️ 注意：需要手动逐个处理，较费时。

========================================
  🔴 Python 脚本方案（沙盒环境限制）
========================================

由于当前 LM Studio 是沙盒环境，Python 无法直接访问你的本地文件系统。

如果你想使用 Python 脚本转换，需要：

1. **将脚本复制到本地环境**
   - 复制 `convert_heic.py` 到本地任意位置
   
2. **安装必要依赖**（如果还没有）：
   ```bash
   pip install libheif-cxx pillow opencv-python-headless
   ```
   
3. **运行转换**：
   ```bash
   cd 你的脚本所在文件夹
   python convert_heic.py
   ```

⚠️ 当前沙盒环境无法直接运行此方案！
