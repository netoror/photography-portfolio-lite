========================================
  方法一：使用 PowerShell（推荐）
========================================

在 Windows PowerShell 中运行以下命令：

# 切换到文件夹
cd "D:\Users\18268\.lmstudio\apps\bionic\projects\d49037d8-47f4-5808-9028-c707de117f8f\workspace\摄影网站\index\images"

# 方法 1.1：使用 Windows 自带功能
foreach ($file in Get-ChildItem *.HEIC) {
    $name = $file.Name.Replace('.HEIC', '')
    # 复制文件并打开（手动另存为）
    Copy-Item $file.FullName "$($name).jpg" -Force
    Start-Process "explorer.exe" -ArgumentList '""" + $file.FullName + """', 'open'
}

# 方法 1.2：如果已安装 ImageMagick（需要先下载安装）
foreach ($file in Get-ChildItem *.HEIC) {
    $name = $file.Name.Replace('.HEIC', '')
    magick "$($file.FullName)" "$($name).jpg" -quality 90
}

========================================
  方法三：使用第三方软件
========================================

推荐软件（Windows）：
1. XnView MP（免费）
2. PhotoConvert HEIC（付费，但功能强大）
3. IrfanView + HEIF 插件

步骤（以 XnView MP 为例）：
   1. 打开 XnView MP
   2. 导入所有 HEIC 文件
   3. 选择「批量转换」→ 格式选择「JPEG」
   4. 点击执行转换
