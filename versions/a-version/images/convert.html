🔄 HEIC → JPG 转换工具

📋 当前 images/ 文件夹中的 HEIC 文件：
💡 转换方法（推荐）：
  • 方法一：在线转换
    访问：cloudconvert.com 上传 HEIC 文件下载 JPG
  • 方法二：PowerShell 批量转换
    复制以下代码到 PowerShell 运行：
# PowerShell 脚本（批量转换 HEIC→JPG）
$dir = "C:\Users\18268\.lmstudio\apps\bionic\projects\d49037d8-47f4-5808-9028-c707de117f8f\workspace\摄影网站\index\images"
Get-ChildItem $dir -Filter "*.HEIC" | ForEach-Object {
    $name = $_.Name -replace '\.HEIC$',''
    ConvertFrom-Hepic $_.FullName | Add-Type -MemberDefinition 'public static byte[] ToBytes(string path){var mem=new System.IO.MemoryStream();System.Drawing.Image img=System.Drawing.Imaging.Image.FromFile(path);img.Save(mem,new System.Drawing.Imaging.ImageFormat.Jpeg);return mem.ToArray();}' | Out-Null
    # 或使用 ImageMagick: convert $_.FullName $name.jpg
}
