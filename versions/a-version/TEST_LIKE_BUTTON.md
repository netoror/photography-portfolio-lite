## 🔍 **如何看到点赞按钮？**

### **方法一：强制刷新浏览器（推荐）**
1. 打开 `摄影网站/index/index.html`
2. 按 **Ctrl + Shift + R** 强制刷新
3. 画廊页面应该能看到右上角的 ❤️图标

### **方法二：清除浏览器缓存**
1. F12 → Application → Storage → Clear site data
2. 刷新页面（F5）

### **方法三：使用隐私窗口**
1. 打开新隐私窗口（Ctrl+Shift+N / Cmd+Shift+N）
2. 拖拽 `index.html`到浏览器

## 🐛 **常见问题排查**

### **问题 1：找不到点赞按钮**
**解决方案：**
```bash
# 步骤 1: 强制刷新浏览器
Ctrl + Shift + R (Windows)
Cmd + Shift + R (Mac)

# 步骤 2: 清除缓存
F12 → Application → Storage → Clear site data

# 步骤 3: 重新打开 HTML
```

### **问题 2：Console 报错**
查看 Console 错误信息，常见错误：
- `Uncaught SyntaxError` → JS 文件有语法错误
- `Cannot read property 'likes'` → LocalStorage 读取失败

### **问题 3：按钮不响应点击**
检查 Console 是否有 `[点赞] ID: X`日志输出
