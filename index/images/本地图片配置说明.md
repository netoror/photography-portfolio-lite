## 🌐 **访问方式选择**

### **方式一：直接打开 HTML 文件（推荐用于本地图片）**

**步骤：**
1. 找到 `index.html` 文件
2. 右键选择「在浏览器中打开」或拖拽到浏览器
3. 地址栏会显示 `file:///.../index.html`

**优点：**
- ✅ 可以直接访问本地图片（`./images/gallery.jpg`）
- ✅ 不需要服务器
- ✅ 支持所有本地文件功能

### **方式二：使用 Python HTTP 服务器**

**步骤：**
1. 打开 PowerShell 或 CMD
2. 进入 `index` 文件夹：

## 🔧 **配置本地图片路径**

如果希望网页始终优先使用本地图片，修改 `js/main.js`：

```javascript
// ==================== 作品集数据 ====================
const portfolioData = [
    { 
        id: 1,
        title: "京都美术馆大厅",
        category: "城市摄影",
        image: "./images/gallery.jpg",          // ← 本地图片路径
        description: "洁白且工整的大厅"
    },
    // ...
];

// ==================== 缩略图生成函数 ====================
function getThumbnailUrl(imagePath) {
    if (imagePath && imagePath.startsWith('./images/')) {
        // 本地图片：直接使用（浏览器可能无法加载 file://路径的图片）
        console.log(`[Gallery] 使用本地缩略图：${imagePath}`);
        
        // ⚠️ 注意：在 file://协议下可以正常使用，但 http://localhost:8080 可能有 CORS 问题
        return imagePath;
    }
    
    // 在线图片：使用 Picsum 占位符
    const seed = imagePath.replace('./', '').replace('.jpg', '');
    return `https://picsum.photos/seed/${seed}/300/225`;
}
```

## ⚠️ **重要提示**

### **CORS 跨域问题说明：**

当使用 HTTP 服务器（`http://localhost:8080`）访问时：
- ✅ HTML、CSS、JavaScript 可以正常加载
- ❌ 本地图片（`./images/*.jpg`）无法加载，因为浏览器阻止跨域请求

**解决方案：**
1. **使用 `file://` 协议** - 直接打开 HTML 文件
2. **转换 HEIC 为 JPG** - 确保图片格式兼容
3. **上传到在线存储** - 如 Imgur、GitHub Pages

---
